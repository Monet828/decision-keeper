# docs/approvals/

承認記録の置き場。**仕様本文とは物理的に分ける**（REQ-B02 / v2.1 §3）。

分けている理由は、後から書き込み制御（hook / CI）をかけられる状態を残すため。
今回はロックまで実装しない（§12）。

## 命名

`docs/specs/<name>/` に対して `docs/approvals/<name>.md`。

## 承認とみなす表現

**対象を特定したうえでの明示的な同意のみ。**

| 承認とする | 承認としない |
|---|---|
| 「承認する」「これで進めて」「OK、実装して」 | 「いいね」「なるほど」「よさそう」 |
| | **無返答** |

曖昧な返答を受け取った場合は、対象を明示して再確認する。
