# デモと評価の候補

全項目未実装。concept.mdの同一事例A/B/Cで、入力の前提と証拠だけを変えて比較する。
A: 前提維持 → 継承・衝突指摘。
B: 前提変化を検証済み → 見直し提案（人間承認待ち）。
C: 根拠不足 → 追加検証または相談。

判断資産なし／ありを同一入力・同一モデル等の条件で比較し、修正の妥当性、誤適用、適切な停止、費用、時間、人の確認負担を記録する。条件・サンプル数・モデル・試行数を明示。小規模デモから一般性能を主張しない。

## 審査との対応
- セキュリティ: 証拠内の命令を実行しない、権限境界、秘密情報の除外、隔離。
- コスト: 工程別モデル・トークン・推定費用と実請求を区別。
- 信頼性: 継承／見直し／保留の境界ケース、上限、エラー復旧。
- 自律性: 状況に応じた追加検証・ツール選択と停止。
- 独創性: 過去の判断の前提が現在も有効かを扱う。市場新規性は別途検証。
