# 項目テンプレート（1 ファイル = 1 ルール）

このファイルをコピーして `review-<短い名前>.md` を作り、`items/README.md` の
一覧に追加する。以下の 5 セクションを必ず埋める。1 ファイルに複数ルールを
詰め込まない（検出と是正の粒度を保つため）。

---

## 根拠 (Basis)
なぜこのルールがあるか。1〜2 行。可能なら AGENTS.md の該当規約を指す。

## 検査対象 (Target)
どのファイル / 言語 / パスに適用するか。除外（生成物・vendor 等）も書く。

## 規約 (Rule)
守るべきこと。必ず ❌ / ✅ の具体例を付ける。

```
❌ 悪い例
✅ 良い例
```

## 検出方法 (Detection)
実行する `grep -nE` を **そのまま貼る**（コピペで動く形）。
誤検出（false positive）の除外条件も明記する。

```sh
grep -nE 'PATTERN' <files>
# 除外: <ここに carve-out を書く>
```

## 報告フォーマット (Report)
検出時の一行フォーマット。基本は:

```
file:line — 問題 — 修正方針
```
